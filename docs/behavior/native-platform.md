# 原生平台行为书

本文约束 Capacitor iOS/Android 壳提供的系统级交互，以及移动浏览器和主屏幕应用的顶部颜色。业务命令、模式、视图和任务层级仍由 Web 应用及各自行为书定义，原生桥只增强输入反馈和设备集成。

## 会话与网络

- **NATIVE-001**：移动壳只连接构建时指定的单一公共 HTTPS origin；缺失、非 HTTPS 或包含路径的地址必须使移动构建失败。
- **NATIVE-002**：原生登录使用独立 Bearer token，不复用浏览器 cookie、MCP key 或浏览器 remember token。
- **NATIVE-003**：勾选记住登录时，token 只写 Android Keystore 加密存储或 iOS Keychain；未勾选时只保留在当前进程内存。
- **NATIVE-004**：原生 API 返回 401、用户退出或账号会话重置时清除设备 token。安全存储暂时无法清除时记录待清理状态，后续启动必须先重试且不得读取旧 token。修改密码撤销旧 token，并只为当前会话签发替换 token。

## 键盘、返回与安全区

- **NATIVE-101**：系统键盘出现时隐藏移动底栏、让编辑控件进入可视区域，并由系统 resize 与安全区共同决定内容空间；键盘关闭后恢复布局。
- **NATIVE-102**：Android 返回键优先级为：退出当前文本编辑并收起键盘 → 关闭顶层弹窗/临时界面 → 回到应用内上一个底部页签 → 回到列表页签 → 最小化应用。
- **NATIVE-103**：状态栏和导航栏图标跟随主题明暗；内容不得依赖固定刘海、Home indicator 或系统栏像素值。移动端顶部工具栏使用系统顶部安全区，并以主题表面承接透明状态栏；页面内容不得与系统状态信息重叠。
- **NATIVE-104**：移动网页向系统提供的顶部颜色必须与网页顶边一致。玻璃主题使用壁纸按当前裁剪、模糊、亮度和主题叠色合成后的顶边代表色；纯色主题、登录页和壁纸未就绪时使用实际页面底色。根画布、iOS 取色层和 `theme-color` 使用同一颜色，随主题、图片就绪、窗口尺寸和登录状态更新。系统预留区域只接受单色时，验收目标是颜色接近，不承诺图片透出或模糊消失。实机证据和复现方法见 [iOS 顶部区域调查](../reviews/2026-10-05-ios-status-bar.md)。
- **NATIVE-105**：移动顶栏在原有按钮布局上方延伸 8 CSS px 的状态区同色带，网页内顶部安全区也使用此颜色；颜色统一读取 NATIVE-104 的 `--page-chrome-color`。按钮组上下各留 8 CSS px，按钮尺寸保持不变；任务和依赖图工具栏为 60 CSS px，更多首页为 56 CSS px，设置子页为 68 CSS px，另加网页内顶部安全区。移动列表中，顶栏按钮到输入框、输入框到任务分区标题的间隔均为 12 CSS px，任务行尺寸保持不变。色带固定在页面动画之外，切页、进入和退出子页、切换主题时不得移动、淡出或保留旧主题颜色。底栏保留原来的图标、文字和上下 8 CSS px 内边距，只把额外底部留白设为系统底部安全区减 8 CSS px、最小为零。任务、依赖图、更多及其子页共用此规则；内容及撤销提示跟随底栏高度，键盘与缩放不得改变栏高。对应端到端测试为 `mobileChrome.spec.ts`、`themeChrome.spec.ts` 和 `chromeTransitions.spec.ts`，Home indicator 和系统色带衔接仍须实机验收。

## 触觉反馈

- **NATIVE-201**：触觉反馈默认开启，可在移动端“更多”中关闭；关闭不改变任何业务行为。
- **NATIVE-202**：触摸长按真正提起任务时仅反馈一次；只有预计落位的语义目标改变时才产生 selection 反馈，指针逐帧移动不得重复震动。
- **NATIVE-203**：有效落位、无效落位和取消分别结束一次 selection 会话；鼠标、浏览器和 Electron 不调用原生触觉反馈。
- **NATIVE-204**：任何原生反馈 API 失败都静默降级，不阻断拖拽、编辑、导航或保存。

## 发布边界

- **NATIVE-301**：Android/iOS 工程是可审查的源代码；Web 资源通过 `build:mobile` 重新构建并同步，不手工修改平台工程中的 `public` 产物。
- **NATIVE-302**：Windows + JDK 21 可生成和验证 Android 工程；iOS 最终编译、签名和真机验证必须在 macOS/Xcode 完成。
